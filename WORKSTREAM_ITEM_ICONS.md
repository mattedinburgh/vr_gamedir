# Item Icons Workstream — 2026

Status: ACTIVE REDESIGN

## Current rule
This branch is the only current-base lane for inventory icon redesign.

Historical branches such as `art/item-icons-pilot-20`, `pilot/inventory-icons-20-2026-09-14`, `save23/inventory-icons-ai-2026-09-14`, and `art/all-inventory-icons-ai-2026-09-14` are source/reference material only. Their binary sheets are not accepted canonical art and must not be bulk-promoted.

## Acceptance rules
- Produce actual in-game assets, not mockups.
- Cross-reference the real-world appearance of the represented item where practical.
- Increase realism, material detail and readability while respecting JA2 inventory constraints.
- Every AI-redesigned icon carries a small red **AI** marker in the top-right corner.
- Validate a pilot batch in game before expanding to the full inventory.
- Graphics deployment is incremental by default; full redeploy is recovery-only.

## Exit
Accepted batches merge to the canonical gamedir and this temporary branch is retired when the redesign programme is complete.
