# Whole-game Vengeance inventory icon replacement

Generated game-ready STI assets for every referenced BigItems graphic plus the MDGUNS/MDP1..7 inventory sheets. Every converted icon carries a tiny red AI stamp in its lower-left corner. Geometry and offsets are preserved.

Nothing is installed automatically. Run INSTALL_ALL_ICONS.ps1 from this folder to install incrementally with automatic backups. Use -Revert to restore.
